# Contract Generate

Generate TypeScript interfaces and typed fetch wrapper functions from an OpenAPI/Swagger specification. Output goes to `src/api/types.ts` and `src/api/client.ts`.

## Steps

### 1. Find and Parse the Schema

Use the same schema discovery order as contract-validate (openapi.yaml → swagger.json → openapi.json → api-spec.yaml → docs/). Parse the spec and resolve all `$ref` references before generating code.

If the spec is OpenAPI 2.x (Swagger), map:
- `definitions` → `components/schemas`
- `host` + `basePath` + `schemes` → `servers[0].url`

### 2. Generate `src/api/types.ts`

Create TypeScript interfaces for every schema in `components/schemas` (or `definitions`):

**Mapping rules:**
- `type: string` → `string`
- `type: integer` / `type: number` → `number`
- `type: boolean` → `boolean`
- `type: array, items: $ref` → `SchemaName[]`
- `type: object, properties: {...}` → inline interface
- `$ref: '#/components/schemas/Foo'` → `Foo`
- `type: string, enum: [...]` → TypeScript string literal union
- `nullable: true` or `type: [string, null]` → `string | null`
- `oneOf` / `anyOf` → TypeScript union type
- `allOf` → TypeScript intersection type
- Required fields → non-optional; non-required → optional (`field?: Type`)
- `format: date-time` → keep as `string` (add JSDoc `@format date-time`)
- `additionalProperties: true` → `Record<string, unknown>`
- `additionalProperties: { type: string }` → `Record<string, string>`

Also generate request body types and response types per endpoint:

```ts
// Named for the operation: {OperationId}Request and {OperationId}Response
// If no operationId, derive from method + path: PostUsersRequest, GetUsersIdResponse
export interface CreateUserRequest {
  name: string;
  email: string;
  role: 'admin' | 'user' | 'viewer';
}

export interface CreateUserResponse {
  id: string;
  name: string;
  email: string;
  role: 'admin' | 'user' | 'viewer';
  createdAt: string; // format: date-time
}
```

Add a file header:

```ts
/**
 * Auto-generated by api-contract plugin
 * Source: openapi.yaml
 * Generated: <ISO timestamp>
 *
 * DO NOT EDIT — re-run /api-contract-generate to update
 */
```

### 3. Generate `src/api/client.ts`

Generate one typed async function per endpoint. Each function:

- Takes typed request parameters (path params, query params, request body)
- Returns a typed `Promise<ResponseType>`
- Uses native `fetch` (no external dependencies)
- Throws on non-2xx responses with the status code and body included

**Function naming:**
- Derive from `operationId` if present: `createUser`, `getUserById`
- If no `operationId`, derive from method + path: `postUsers`, `getUsersById`

**Template per function:**

```ts
export async function createUser(
  body: CreateUserRequest,
  options?: RequestInit
): Promise<CreateUserResponse> {
  const response = await fetch(`${API_BASE_URL}/users`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', ...options?.headers },
    body: JSON.stringify(body),
    ...options,
  });
  if (!response.ok) {
    throw new Error(`POST /users failed: ${response.status} ${await response.text()}`);
  }
  return response.json() as Promise<CreateUserResponse>;
}
```

**Path parameters:**

```ts
export async function getUserById(
  params: { id: string },
  options?: RequestInit
): Promise<GetUserByIdResponse> {
  const response = await fetch(`${API_BASE_URL}/users/${params.id}`, {
    method: 'GET',
    ...options,
  });
  if (!response.ok) {
    throw new Error(`GET /users/${params.id} failed: ${response.status} ${await response.text()}`);
  }
  return response.json() as Promise<GetUserByIdResponse>;
}
```

**Query parameters:** append to URL with `URLSearchParams`.

Add at the top of `client.ts`:

```ts
/**
 * Auto-generated by api-contract plugin
 * Source: openapi.yaml
 * Generated: <ISO timestamp>
 *
 * DO NOT EDIT — re-run /api-contract-generate to update
 */

import type { ... } from './types';

const API_BASE_URL = (typeof process !== 'undefined' && process.env.NEXT_PUBLIC_API_URL)
  || (typeof import.meta !== 'undefined' && (import.meta as any).env?.VITE_API_URL)
  || '';
```

### 4. Write Files

Write `src/api/types.ts` and `src/api/client.ts`. If either file already exists and was not previously auto-generated (no "DO NOT EDIT" header), warn before overwriting:

```
Warning: src/api/types.ts exists and does not appear to be auto-generated.
Overwrite? (Proceeding — backup at src/api/types.ts.bak)
```

Create a `.bak` copy before overwriting manually-edited files.
